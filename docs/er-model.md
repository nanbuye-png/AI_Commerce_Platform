## 2. 核心 ER 关系图

### 2.1 用户 → 订单 → 支付 → 退款

```
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  user      │     │  order     │     │  payment   │     │  refund    │
│  _account  │     │  _info     │     │            │     │            │
└─────┬──────┘     └─────┬──────┘     └─────┬──────┘     └────────────┘
      │                  │                  │                  │
      │ 1:N              │ 1:1              │ 1:N              │
      │                  │                  │                  │
      ▼                  ▼                  ▼                  │
 ┌────────────┐     ┌────────────┐                         ┌────────────┐
 │  order     │─────│  payment   │─────────────────────────│  refund    │
 │  _info     │     │            │     (payment_id)        │            │
 └────────────┘     └────────────┘                         └────────────┘
```

### 2.2 用户 → 购物车 → 购物车条目 → SKU

```
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  user      │1:1  │   cart     │1:N  │  cart_item │N:1  │  product   │
│  _account  │────>│            │────>│            │────>│  _sku      │
└────────────┘     └────────────┘     └────────────┘     └────────────┘
```

### 2.3 商品 → SKU → 库存 → 库存流水

```
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  product   │1:N  │  product   │1:1  │ inventory  │1:N  │  inventory │
│            │────>│  _sku      │────>│            │────>│  _record   │
└────────────┘     └────────────┘     └────────────┘     └────────────┘
                                           │
                                           │ version（乐观锁）
                                           ▼
                                      防超卖控制
```

### 2.4 商家 → 店铺 → 商品

```
┌────────────┐     ┌────────────┐     ┌────────────┐
│  merchant  │1:N  │   store    │1:N  │  product   │
│  _account  │────>│            │────>│            │
└────────────┘     └────────────┘     └────────────┘
      │ 1:N
      ▼
┌────────────┐
│  merchant  │
│  _user     │
└────────────┘
```

### 2.5 AI 对话链路

```
┌────────────┐     ┌────────────┐     ┌────────────┐
│  user      │1:N  │conversation│1:N  │  message   │
│  _account  │────>│            │────>│            │
└────────────┘     └────────────┘     └────────────┘
```

### 2.6 媒体关联

```
┌────────────┐     ┌────────────┐
│  media     │1:N  │  media     │
│  _file     │────>│  _relation │
└────────────┘     └────────────┘
                         │ N:1
                         ▼
                    ┌────────────┐
                    │  product   │  (target_type='product')
                    │  ai_image  │  (target_type='ai_image')
                    │  ...       │
                    └────────────┘
```

## 3. 关键关系总结

| 关系 | 类型 | 说明 |
|------|------|------|
| user_account : user_address | 1:N | 一个用户多个地址 |
| user_account : cart | 1:1 | 一个用户一个购物车 |
| cart : cart_item | 1:N | 一个购物车多个条目 |
| cart_item : product_sku | N:1 | 多个条目可指向同一 SKU |
| user_account : order_info | 1:N | 一个用户多个订单 |
| order_info : order_item | 1:N | 一个订单多个条目 |
| order_item : product_sku | N:1 | 多个条目可指向同一 SKU |
| order_info : payment | 1:1 | 一个订单一个支付记录 |
| payment : refund | 1:N | 一个支付多次退款 |
| merchant_account : store | 1:N | 一个商家多个店铺 |
| merchant_account : merchant_user | 1:N | 一个商家多个员工 |
| store : product | 1:N | 一个店铺多个商品 |
| product : product_sku | 1:N | 一个 SPU 多个 SKU |
| product : product_image | 1:N | 一个 SPU 多张图片 |
| product_sku : inventory | 1:1 | 一个 SKU 对应一个库存 |
| inventory : inventory_record | 1:N | 一个库存多条变动记录 |
| user_account : conversation | 1:N | 一个用户多个对话 |
| conversation : message | 1:N | 一个对话多条消息 |
| user_account : ai_memory | 1:N | 一个用户多条记忆 |
| user_account : recommendation_record | 1:N | 一个用户多条推荐 |
| user_account : agent_task | 1:N | 一个用户多个任务 |
| agent_task : agent_task_step | 1:N | 一个任务多个步骤 |
| media_file : media_relation | 1:N | 一个文件多次关联 |

## 4. 核心查询路径

### 4.1 用户下单全链路

```
user_account ──> order_info ──> order_item ──> product_sku
                    │
                    └──> payment ──> refund
```

### 4.2 商品详情展示链路

```
merchant_account ──> store ──> product ──> product_sku
                                       │
                                       └──> product_image
                                       └──> inventory
```

### 4.3 AI 推荐链路

```
user_account ──> user_behavior ──> (推荐算法) ──> product
                    │
                    └──> recommendation_record ──> product
```

### 4.4 搜索链路

```
product ──> (ES index) ──> 搜索结果 ──> product_sku (详情)
```
